# Algorithmic-Methods-Homework
Repository containing the homework required in the Algorihmic Methods of Data Mining

The folder called printouts contains the screenshots of the submissions in cronological order and the file scripts.py contains all the scrips used to solve the challenges in the same order as in printouts. Note that to match each solution to each problem the screenshots must be read from first to last, but from last to first inside every singular screenshot. Also note that some challenges may repeat in the screenshots or they may be signed as failed even if the solutions are correct for some reason
